# DevNotebook

DevNotebook keeps project notes attached to Unity content so scene review, asset follow-up, and polish tasks stay close to the work.

## Features

- Notebook assets stored in the project
- Sections, pages, checklist items, tags, and page status
- Scene and asset links with quick open and ping actions
- Project Settings integration for startup behavior
- Getting Started window with recent work and sample import

## Quick Start

1. Create a notebook from `Assets/Create/DevNotebook/Notebook`.
2. Open `Window/DevNotebook/Notebook`.
3. Add a section, create a page, and link your current scene or selected assets.
4. Review notes later with search, status, and current-scene filters.

## Sample Content

Use `Window/DevNotebook/Getting Started` and choose `Open Sample` to copy the sample notebook into `Assets/DevNotebooks/DevNotebook Sample`.

## Project Layout

- Tool files live under `Assets/DevNotebook`.
- Notebook assets default to `Assets/DevNotebooks`.
