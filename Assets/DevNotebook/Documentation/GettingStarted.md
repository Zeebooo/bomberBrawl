# DevNotebook Getting Started

## Core Flow

1. Create a notebook from `Assets/Create/DevNotebook/Notebook`.
2. Open `Window/DevNotebook/Notebook`.
3. Add a section and page.
4. Link the current scene or selected assets.
5. Reopen the same work later from Getting Started or recent notebook history.

## Notes

- Notebook data lives in project assets.
- New notebooks default to `Assets/DevNotebooks`.
- Startup behavior is controlled in `Project Settings/DevNotebook`.
- `Open Sample` copies starter content into the project so you can edit it safely.
